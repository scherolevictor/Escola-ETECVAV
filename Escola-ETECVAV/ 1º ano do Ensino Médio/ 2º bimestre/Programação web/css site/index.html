Linguagem CSS

O que é CSS?

O CSS (Cascading Style Sheets) é a linguagem que define o estilo das páginas da web. Ele trabalha junto com o HTML, que organiza o conteúdo, enquanto o CSS cuida da aparência.
É graças a ele que conseguimos transformar páginas simples em layouts bonitos e organizados.
Com o CSS, podemos escolher cores, fontes, tamanhos, espaçamentos e até criar efeitos de animação.
Ele é essencial porque separa o conteúdo da apresentação, permitindo que o texto e as informações fiquem em HTML,
enquanto o visual é controlado pelo CSS. Isso facilita a manutenção e garante consistência em todo o site.

Seletores

Os seletores são usados para indicar quais elementos do HTML receberão o estilo. Eles funcionam como endereços que apontam para partes específicas da página.
Por exemplo, podemos selecionar todos os parágrafos, apenas os títulos ou até um botão específico.
Graças aos seletores, conseguimos aplicar estilos diferentes em cada parte do site, criando hierarquia e organização visual. É como dizer ao CSS: “aplique este estilo aqui”.

Propriedades

As propriedades são os aspectos visuais que podem ser modificados em um elemento. Cada propriedade corresponde a uma característica da página.
Podemos alterar a cor do texto, o tamanho da fonte, o fundo de um bloco ou o espaço ao redor de uma imagem.
As propriedades são como opções que o CSS oferece para personalizar cada detalhe da aparência de um site.

Valores

Os valores são os ajustes aplicados às propriedades. Eles definem como a propriedade será exibida.
Se a propriedade é “cor”, o valor pode ser “azul”;
se a propriedade é “tamanho da fonte”, o valor pode ser “20px”.
Essa combinação de propriedade e valor é o que dá vida ao estilo de uma página.
É como escolher não apenas o que mudar, mas também como essa mudança deve aparecer.

Conclusão

Esses exemplos mostram como a combinação de propriedade + valor é usada para personalizar o estilo de uma página.
É como dar instruções específicas: “mude a cor para azul”, “aumente a fonte para 18px” ou “arredonde as bordas em 10px”.
Cada detalhe ajuda a construir um layout mais bonito, organizado e responsivo.
